# 画布优先的 Agent 设计页

日期：2026-09-28；OpenSpec：`refine-builder-focus`。

## 用户需求与设计取舍

用户要求以自行部署后实际使用者的视角精简设计页，并提供 Dify 编辑器截图作参考。Coding Agent 审查了现有代码、用户截图和 https://mobilerun.ai/ 公开首页；没有进入或修改用户的 Dify 项目。Dify 参考点为画布优先、上下文配置、收敛主操作；MobileRun 首页以设备和任务为主，不作为本项目画布执行语义依据。

原界面同时展示全局导航、面包屑、Agent 身份、操作栏、长期打开的两侧面板和底部布局说明。现行设计页移除重复面包屑，压缩身份栏，取消底部布局说明和常驻连线提示。能力库通过“添加能力”打开，支持按名称或用途搜索；默认保留画布空间。选中节点、边或出现新的失败校验结果时，配置面板自动显示，也可手动打开或收起。窄屏采用覆盖式面板。

保存和试跑使用中文文案，保存为次级操作，试跑为主操作。正常运行配置状态放入技术详情，异常仍直接显示。试跑仍先进入现有准备流程；没有添加自动运行或自动保存。能力库展示用途而非实现数量和端口清单；端口预览仍保留在可访问名称中，实际端口仍在画布。内置示例描述改用中文用途，自定义描述不覆盖。隐藏无助于操作的 CORE 标签和常驻图例，反馈标签/连线类型选择保留。

右侧常用参数优先，高级参数 JSON 默认折叠；首选实现的原始参数输入错误会展开。所有原始输入继续由既有 store 持有，折叠不清空字段。参数字段名称和组件名称继续采用 Catalog 合同，未臆造全套中文翻译。

## 验证

- 144 个测试文件、674 个测试通过，包含面板显示不改变选择/文档、保存冲突、原始字段缓冲、校验、连接、撤销等回归。
- ESLint、TypeScript 与生产构建通过；既有超过 700 kB 的 bundle 提示仍在。
- 真实本地后端浏览器：已有 Agent 设计页、能力库开合、搜索输入、节点选择自动展开配置、显示全图、1440×900 桌面与 390×844 窄屏配置面板检查。
- 本轮未保存或修改用户 Agent 内容，未提交设备任务，也没有新增模型/Android 执行证据。

```sh
cd studio
npm test
npm run lint
npm run build -- --outDir /tmp/zhixing-builder-focus-dist
```

手动验收：进入任一已有 Agent 的设计页，预期默认画布展开；点“添加能力”可查找能力，点节点打开参数；高级 JSON 默认收起，修改无效 JSON 时保存仍被阻止。仅查看和折叠面板不会使草稿变脏。保存/试跑继续使用原先的校验和版本冲突边界。

## 限制

本轮是编辑器信息层级调整，没有重新定义普通关系与反馈回路，也没有新增连线算法或拖拽性能基准。大型图仍需缩放、平移和自动整理。窄屏可阅读配置，但复杂画布编辑仍建议桌面。精确实现标识、Catalog 参数和高级诊断可能保留英文。
