# Studio 画布拖拽与可读性改进

2026-09-28；OpenSpec：`improve-builder-canvas-interaction`。
用户指出搭建过程抽象、图形混乱、拖拽卡顿并授权修改。本次由 Coding Agent 实现与验证，范围是现有单画布的交互、布局和渐进信息展示，没有重写 Agent 编译或运行语义。

## 改动

- **拖动即时更新**：原受控 ReactFlow 只在拖动结束保存位置，缺少 `onNodesChange` 反馈。现在移动和尺寸变化先写入 React 局部投影；松手后一次性提交所有移动节点的位置。一次撤销恢复整次拖动；旧编辑会话的结束回调不能改写新会话。
- **减少重绘**：局部拖动复用未移动节点和节点数据；节点内容通过 memo 保持稳定。拖动每帧不重新解析文档、不重建语义图、不追加历史。
- **按尺寸整理**：自动整理考虑测量尺寸与完整端口展开的保守尺寸，按列宽与各分区堆叠高度安排位置。操作显式触发，可撤销，不覆盖用户已有布局。
- **连线可读性**：普通连接改为圆角折线，反馈沿整图下方的独立返回通道；选中连接显示关系种类和端口文字，选中对象时无关线条淡化，带诊断的线仍保持可见。
- **节点与端口**：卡片更宽、标题和端口字号增大。未使用的可选输入默认收起；必需输入、已连接输入、边界端口保持可见。选择节点、查看关联边或发起连接时展开。连接点命中区域为 28px，连接吸附半径设置为 28。
- **视野操作**：新增“100%”恢复实际字号、“显示全图”包含反馈通道。展开或恢复面板后重新适应画布尺寸。缩放和平移不成为文档编辑。

## 手动复查

已有开发服务可以刷新页面加载新代码；若服务未开，从项目根目录运行：

```bash
conda activate unimobile
python run_studio.py
```

1. 打开已有 Agent 的设计页，点击“自动整理”。这是布局修改，需要自行保存才写入新版本；不想保留可撤销。
2. 展开画布查看全图；点击“100%”编辑，拖动空白区平移。
3. 连续拖动一个节点再松手；点一次撤销应恢复整次移动，重做应恢复落点。
4. 选中 Reasoning 应展开计划等可选输入。发起连线应显示兼容目标，既可以拖动也可以点选两端。
5. 选中一条关系查看其说明；取消选中后恢复全图连线显示。

```bash
cd studio
npx vitest run src/features/agent-builder
npm test
npm run lint
npm run build
```

## 限制与取舍

- 本次不是完整的自然语言/流程向导式 Builder 重做，没有新增循环容器、分支编辑器或数据来源表单。现有合法能力和关系保持原意。
- 任意手动摆放的图仍可能存在交叉；当前不是全局避障布线算法。多个反馈通道有独立间距，但大型多环图仍需后续验证。
- 全图概览会缩小文字，实际编辑使用 100% 和平移。宽窄屏、大规模节点的帧率/延迟没有量化基准；不能声称稳定 60 FPS。
- 连续位置反馈由组件测试证明，浏览器验证实际拖动落点与撤销；没有在浏览器中录制逐帧性能轨迹。
- 收起的是可选输入展示，不删除契约端口。布局使用展开尺寸预留空间，以更宽松的图换取展开时不覆盖邻居。
