## 设计与边界

- Home 复用独立资源查询，各分区独立处理读取失败；配置检查不会主动连接设备或调用模型。
- Replay 列表新增可选 `agentName`（240 字符）和 `taskSummary`（500 字符），在同一 SQLite 查询内按普通本地 Run 与 Agent 身份关联。无可信本地关联的导入记录显示未记录；旧 DTO 缺少字段仍能读取。名称是当前显示名称，不是运行时冻结名称。摘要不进入规范身份，不需要数据库迁移。
- 历史搜索仍只搜索当前页，不是全库检索。首页任务结果来自已有 Replay，不包含尚未发布回放的活跃 Run。
- 复制原任务要求普通本地 Replay、原 Run 与不可变版本身份一致。复制只更新页面草稿，包含原附加信息；不会自动执行，不把任务存进 URL 或浏览器存储。提交复用现有幂等创建流程。
- 模型摘要只提取声明的模型名称与执行预算；不展示密钥和接口地址，也不是价格或实际调用次数估算。旧版本缺失相关声明时明确显示不可用。
- 回放先展示最终位置；仍可从头播放、选择步骤。缺少的模型输出仍显示未采集，不根据事件猜测推理过程。最后截图不等于 Benchmark 判定成功。
- 自定义前端端口的浏览器写请求原来会被固定来源列表拒绝。本次启动器把选定端口传给后端，只添加该端口的两个精确本机来源；外部来源仍拒绝。

- 前端完整测试：142 个文件、661 项通过。新增覆盖配置缓存过期、原任务显式复制、模型字段安全摘要、历史可选字段/Unicode 边界与最终回放初始位置。
- 后端 Replay / Run HTTP 回归：21 项通过。
- 启动器、真实 API/Vite 生命周期、自定义端口与 HTTP 来源边界：35 项通过。真实代理写请求验证可信来源进入参数校验，外部来源返回 403；测试没有创建或运行任务。
- ESLint、TypeScript 与生产构建通过。构建仍提示主 bundle 大于 700 kB，此次没有进行加载体积优化。
- 真实浏览器使用用户数据库的临时副本及已有证据目录，在独立端口验收：首页缓存过期、按 `UX Audit` 搜索两条历史、失败回放直接显示最后截图/中文停止原因、复制原任务、示例创建后直达运行准备页并填入观察任务。
- 本次浏览器仅在临时副本创建一个 Agent，没有提交新的设备任务或模型请求；既有成功/失败 Android Run 来自调研阶段，不属于本次新增执行证据。用户原服务与数据库没有被本次验收替换。

## 手动复查

先在旧服务终端按 Ctrl+C，再从项目根目录启动（后端列表字段与端口逻辑需要重启）：

```bash
conda activate unimobile
python run_studio.py
```

1. 首页等待十余秒：允许变成“待复查”，不应把上次配置齐全变成缺配置。
2. 选择“从示例开始”→“创建并准备试跑”：应进入运行页，看到模型、15 步/10 轮默认预算及设备；不会自动运行。
3. 手动打开 Android 设置首页，点击“填入观察示例”，检查内容后自行点击运行。实际结果取决于设备连接和模型能力，不保证成功。
4. 在历史页以本页已有 Agent 名称搜索；打开已终止的回放，确认最终位置和已有截图。
5. 点击“复制原任务”：应只填充草稿，原记录不变；修改并提交才是一次新运行。

可复现测试：

```bash
cd studio
npm test
npm run lint
npm run build
cd ..
```
