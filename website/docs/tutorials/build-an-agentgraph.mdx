# Inspect an AgentGraph

## What you will achieve

Load, validate, and run the checked-in deterministic AgentGraph. This is a
safe way to learn the graph contract before connecting a device or configuring
a model provider.

## Steps

```python
from zhixing.graph import load_graph_yaml

result = load_graph_yaml("examples/agent_graph/agent_graph_v1.yaml")
if not result.is_success:
    raise ValueError(result.to_safe_dict())

graph = result.graph
print(graph.canonical_hash())
```

Run the snippet from the repository environment after installation. It only
compiles the definition; it does not bind component implementations or perform
device actions.

## Verify the result

The hash begins with `sha256:`. It represents execution-relevant graph
semantics, not canvas-only presentation fields such as positions, icons, or
labels.

Then execute the same graph with repository-provided fake components:

```bash
python examples/agent_graph_runtime_no_device.py
```

The output includes the same canonical hash, ordered node events, and a final
`"status": "success"`. It performs fake observations and fake actions only;
it does not contact a phone or model provider.

## Read the YAML before changing it

Open `examples/agent_graph/agent_graph_v1.yaml`. Its envelope declares
`kind: agent_graph`, schema version, nodes, edges, and execution policies. The
example deliberately includes a bounded feedback edge from verifier to
reasoning. Do not create an unrestricted cycle: the contract requires explicit
feedback bounds and exhaustion behavior.
