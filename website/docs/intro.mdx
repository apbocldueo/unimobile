# ZhiXing documentation

ZhiXing is a backend-first framework for composing, running, and evaluating Mobile Agents. It keeps Agent behavior, task evaluation, and experimental conditions as separate definitions, so an Agent can be inspected and compared without silently changing the task around it.

## Start here

1. [Install ZhiXing](getting-started/installation) and run the no-device example.
2. [Run your first AgentGraph](getting-started/first-agent) to see the core execution path without a phone or model key.
3. Choose a focused tutorial: [build an AgentGraph](tutorials/build-an-agentgraph), [run on Android](tutorials/run-on-android), or [run a benchmark](tutorials/run-a-benchmark).

## How to read these docs

Prefer a visual walkthrough? [Create your first Agent in Studio](tutorials/studio-first-agent) follows the actual interface from startup to a saved, validated graph, with screenshots at each important step.

- **Get started** is the shortest safe path to a working local run.
- **Tutorials** take you through one complete outcome at a time.
- **Concepts** explain the design choices behind the commands and artifacts.
- **Reference** points to detailed source documents while their user-facing counterparts are expanded.

## Scope

ZhiXing is an alpha research and engineering framework. It has verified fake-device and bounded Android evidence; it does not claim arbitrary Agent paradigms, arbitrary Android tasks, broad device compatibility, automatic failure diagnosis, or secure sandboxing for arbitrary third-party plugins.
