# ZhiXing documentation site

This directory contains the public documentation site, built with the official
[Docusaurus](https://docusaurus.io/) TypeScript classic template.

English source pages live in `docs/`. Complete Simplified Chinese counterparts
for the launch pages live in `i18n/zh-CN/`.

## Local preview

```bash
npm install
npm run start
```

## Validation

```bash
npm run typecheck
npm run build
```

The site is configured for GitHub Pages at
`https://apbocldueo.github.io/unimobile/`. The repository deployment workflow
publishes successful `release-v2` documentation-site changes once GitHub Pages
is configured to use GitHub Actions.
