# ZhiXing 文档

ZhiXing 是一个以后端为先的移动智能体组合、运行与评测框架。它将智能体行为、任务评测和实验条件保持为彼此独立的定义，因此可以检查和比较智能体，而不会在不知情时改变任务本身。

## 从这里开始

1. [安装 ZhiXing](getting-started/installation)，并运行无设备示例。
2. [运行第一个 AgentGraph](getting-started/first-agent)，在无需手机和模型密钥的情况下了解核心执行路径。
3. 选择一个目标明确的教程：[构建 AgentGraph](tutorials/build-an-agentgraph)、[在 Android 上运行](tutorials/run-on-android) 或 [运行 Benchmark](tutorials/run-a-benchmark)。

## 如何阅读本文档

- **快速开始**提供最短且安全的本地可运行路径。
- **教程**一次带你完成一个完整结果。
- **概念**解释命令和产物背后的设计。
- **参考**在面向用户的文档逐步完善期间，指向详细的源文档。

## 范围

ZhiXing 是 alpha 阶段的研究与工程框架。它具有已经验证的 fake-device 与受限 Android 证据；并不宣称支持任意智能体范式、任意 Android 任务、广泛设备兼容性、自动失败诊断，或任意第三方插件的安全沙箱。
