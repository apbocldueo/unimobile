# 配置模型密钥

## 目标

将本地值绑定到 AgentGraph 的 `SecretRef`，而不把 API key 写入 YAML、canonical hash、报告、轨迹或 Git。

## 开始前

内置 Android Agent 使用 `api_key` 和 `base_url` 两个 secret identity。查看 `examples/graphs/builtin_android_agent.yaml`：其模型依赖包含 `{secret_ref: api_key}` 和 `{secret_ref: base_url}`，而不是字面凭证。先安装可选模型依赖：

```bash
python -m pip install -e ".[openai,dev]"
```

## 创建本地映射

在仓库根目录创建 `secrets.local.yaml`：

```yaml
api_key: "replace-with-your-runtime-key"
base_url: "https://your-openai-compatible-endpoint/v1"
```

仓库会忽略 `secrets.local.yaml`。不要把真实值写进 AgentGraph YAML、示例、issue report 或提交的文件。

## 在运行时绑定密钥

只将映射传给需要它的运行：

```bash
zhixing run \
  --agent examples/graphs/builtin_android_agent.yaml \
  --instruction "Open the camera and take one photo, then finish." \
  --serial emulator-5554 \
  --secrets secrets.local.yaml \
  --artifact-root temp/runs \
  --json
```

将 serial 替换为你的准确 ADB 目标。CLI 读取字符串键 YAML mapping，并只在绑定运行时依赖时解析它。

## 安全地验证

成功 JSON 输出包含 canonical hash、run ID、状态和 artifact manifest 路径，不得暴露 key value。缺失或格式错误的 mapping 会在正常 Agent 执行前成为配置失败；应修复本地文件，而不是把 secret 写进图。

## 范围

secret reference 是 identity boundary，不是 vault 或第三方 secret manager。请使用正常的操作系统和 CI secret 控制来保护本地文件。
