# 安装

## 你将完成什么

在本地安装 ZhiXing，并确认命令行界面可用。此路径需要 Python 3.10 或更高版本，不需要设备或 API 密钥。

## 步骤

```bash
git clone https://github.com/apbocldueo/unimobile.git
cd unimobile
python -m pip install -e ".[openai,dev]"
zhixing --help
```

可编辑安装适合贡献者和直接使用仓库的用户。如果不需要 OpenAI 驱动的组件，可以去掉 `openai` extra。

## 验证结果

`zhixing --help` 应输出可用命令。如果找不到该命令，请在用于安装的同一个 Python 环境中执行它。
