# 安装

## 你将完成什么

在本地安装 ZhiXing，并确认命令行界面可用。此路径需要 Python 3.10 或更高版本，不需要设备或 API 密钥。

## 步骤

```bash
git clone https://github.com/apbocldueo/unimobile.git
cd unimobile
python -m pip install -e ".[dev]"
zhixing --help
```

可编辑安装适合贡献者和直接使用仓库的用户。这条最小路径支持仓库中的无设备示例和合同测试。只有在使用需要 OpenAI-compatible 模型提供者的 Agent 定义前，才添加可选的 `openai` extra：

```bash
python -m pip install -e ".[openai,dev]"
```

## 验证结果

`zhixing --help` 应显示 `run`、`components` 和 `benchmark` 命令。如果找不到该命令，请在用于安装的同一个 Python 环境中执行它。该包需要 Python 3.10 或更高版本。
