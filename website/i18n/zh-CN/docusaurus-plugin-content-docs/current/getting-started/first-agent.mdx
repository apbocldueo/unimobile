# 运行第一个 AgentGraph

## 你将完成什么

在本地运行一个确定性的 AgentGraph。该示例验证图构建和运行时行为，不会连接手机、模型提供商或外部服务。

## 前提条件

先在仓库克隆中完成[安装](installation)。

## 步骤

```bash
python examples/agent_graph_runtime_no_device.py
```

## 验证结果

命令应成功结束，并输出确定性的运行时结果。这是有意设计的无设备示例：不涉及手机连接，也不涉及模型凭证。
